# 桂花图书馆

一个面向多人分享阅读记录的小型社区，也是持续实践前后端开发、测试、部署和线上运维的个人项目。

访客可以浏览书籍、阅读状态、书评和评论；登录用户可以发布自己的阅读记录、参与评论；管理员维护内容与用户。

**当前状态：只有设计文档，尚无应用代码、可运行工程或已上线环境。**
