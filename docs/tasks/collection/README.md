## 背景、目标与范围

建设个人书库图册：访客查看已发布书籍、阅读状态、介绍、书评和公开评论；登录用户维护资料、发布书籍与原生评论；管理员管理书籍、用户与角色。技术方向是 Vue 3/Vite、NestJS、MongoDB/Mongoose 和 pnpm workspace。

本合集把平台任务描述、已批准计划和执行步骤整理为无需 HiFox 访问权限也能理解的交接资料。每份任务保留原始描述，补充目标模块、契约、TDD 矩阵、验收与迁移/回滚说明；原始验收记录仍在 `docs/tasks/HSQL-N.md`。

本次不实现应用、不启动其他 Agent、不部署、不修改远程 `dev` 或替任务宣称验收通过。未确认的删除、账号和外部资源规则见 [待决事项](DECISIONS.md)。
