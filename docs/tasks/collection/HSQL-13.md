## 6. TDD 测试矩阵

以下是执行目标，除 HANDOFF 明确引用的历史检查外，本合集没有运行这些应用测试。

| 维度 | 先失败的断言/反例 | 正常、边界、错误与回归通过标准 |
|---|---|---|
| 认证/所有权 | 匿名写入、客户端伪造身份或非所有者成功时失败 | 会话 owner 创建/维护自己的资源，管理员分支按冻结权限矩阵 |
| 书籍状态/唯一性 | 非法 status、重复 slug、未确认生命周期被隐式启用时失败 | reading/finished 合法创建，冲突 409，发布后能公开读取 |
| 评论安全 | HTML/控制字符/超限或隐藏书籍评论写入成功时失败 | 纯文本评论创建/编辑、作者维护、公开读取脱敏 |
| 删除/隐藏 | 隐藏或删除后仍从列表/按 ID 可见时失败 | 按确认状态机过滤，重复操作和失败回滚符合契约 |
| 限流/UI/回归 | 超额写入未受限、UI 成功但数据未落库时失败 | 429 稳定；真实表单→写 API→公开读取，原有认证/只读路径通过 |

RED/GREEN 必须记录同一测试命令和真实退出码，不把语法/安装失败当作行为红测；不删断言、不零测试成功。安全/兼容性/失败回滚要求见 EXECUTION，不得用文档存在替代运行验证。
