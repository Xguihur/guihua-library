## 决策记录格式

每项 ADR 记录编号、关联任务、现有依据、候选方案、采用方案、批准/技术决定依据、生效版本、输入输出/状态/错误的变化、测试、迁移与回滚。用户修改计划时新增版本并保留旧版历史；本合集更新只记录真实变化，不能静默改已批准契约。
