## 1. 交付目标与范围

交付可运行的 Vue 3/Vite + NestJS/Mongoose + MongoDB pnpm workspace，含公开阅读记录列表、状态筛选、详情、只读评论、开发演示数据、隔离测试数据库、自动化检查及最小 CI。

books 在本阶段代表发布者的一条独立阅读记录，包含自己的 status/review；同一书名允许多条记录，评论归属具体记录。不建立全局公共书目或去重服务。后续若拆公共书目需明确迁移。

不实现注册、登录、OAuth、发布/编辑、后台、角色管理、外部评论、生产部署、缓存或队列。匿名调用已规划的书籍/评论写接口必须 401，不能创建内容；不要用假登录或内存 fallback 模拟未来实现。

## 2. 工程与架构

- apps/web：Vue 3、Vite、TypeScript，路由 /books 与 /books/:bookId，根路径跳转书库。
- apps/api：NestJS，/api 前缀，配置校验、统一错误、Mongoose 数据访问、健康检查及公开资源。
- packages/contracts：浏览器安全的 schema/类型、状态、分页、公开 DTO 和错误结构；web/API 必须实际消费，禁止传 Mongoose 文档。
- 不建只有一实现的通用 repository 抽象、微服务或空配置包。复用成熟工具，依赖版本经 registry/安装验证后锁定，保留 pnpm-lock.yaml。
- 已探测 Node 22.22.1、pnpm 11.5.2、Docker 29.4.0、Compose v5.1.2；依赖的 engines 兼容性由实施者核验，不能伪造通过。
- 配置 .env.example、.gitignore、固定运行版本。缺必需环境变量启动失败；错误不打印 URI、凭据或堆栈。Vite 代理 /api 至本地 API，避免宽松全域 CORS。

## 3. 数据与 HTTP 契约

MongoDB books：id(ObjectId)、ownerId、slug(唯一)、title、author、coverUrl、status(reading/finished)、visibility(published/hidden)、summary、review、createdAt/updatedAt。users 仅提供 owner 公开资料投影所需模型/演示夹具，不实现账号流程；comments：bookId、authorId、content、visibility、createdAt/updatedAt。公开作者仅 id、username、avatarUrl。所有输出显式白名单映射。

- GET /api/books?status=reading|finished&page=1&pageSize=20 → 200 {items,page,pageSize,total}。
- GET /api/books/:bookId → 200 公开详情；非法 ObjectId 400 VALIDATION_ERROR，合法不存在/hidden 均 404 NOT_FOUND。
- GET /api/books/:bookId/comments?page=1&pageSize=20 → 200 同形分页；先校验书籍公开性，隐藏/不存在 404，过滤隐藏评论。
- POST /api/books、POST /api/books/:bookId/comments → 401 UNAUTHORIZED，真实 HTTP 验证，数据库不变。
- GET /api/health/live → 200 {status:"ok"}；GET /api/health/ready → DB 可用 200，不可用 503 SERVICE_UNAVAILABLE，不回显连接信息。
- page/pageSize 必须十进制正整数，默认 1/20，pageSize 上限 100；非法值、非法 status、未知查询参数均 400。排序固定 createdAt 降序 + _id 降序，保证稳定；越界页返回空 items 和准确 total。
- 列表 DTO：id、slug、title、author、coverUrl、status、summary、owner(公开资料)、createdAt/updatedAt；详情增加 review；评论 DTO：id、bookId、content、author(公开资料)、createdAt/updatedAt。
- 错误统一 {error:{code,message,details,requestId}}，响应 HTTP 状态和 code 成对断言；数据库不可用返回脱敏 503。
- schema 输入/输出约束、索引与实现一致：books(visibility,status,createdAt,_id)、comments(bookId,visibility,createdAt,_id)、slug unique。输出 id 为字符串，日期 ISO。
- 内容通过 Vue 文本插值渲染，禁止 v-html。封面仅允许 http(s) URL；页面有缺图/加载失败占位。M1 无上传/服务端抓取。

## 4. 环境与命令

本地 dev MongoDB 与 test MongoDB 使用不同 Compose service、端口与数据卷，端口只绑定 127.0.0.1；命名 guihua-library-* 避免碰其他项目。测试显式 TEST_MONGODB_URI，不从 MONGODB_URI 回退。测试/重置必须检查本地 host、明确 test 数据库名与测试服务端口白名单，不允许任意库 drop；在破坏操作之前检查。dev/test 可同时运行。CI 使用独立 Mongo service，可显式测试端口，保持安全校验。

根命令：dev、typecheck、lint、test(离线一次退出)、build、test:integration(真实 Mongo，依赖不可用失败)、smoke(真实 API+浏览器流程)、db:dev:up/down、db:test:up/reset/down、db:seed。

- db:seed 仅写开发库中明确属于本项目的演示夹具，重复运行幂等；不 drop 开发库，不自动写生产环境。提供 reading/finished、隐藏书籍、公开/隐藏评论和含敏感字段的用户，验证 DTO 脱敏。
- db:test:reset 仅清理专用 test 库，幂等；用 dev 哨兵验证隔离，测试后只删本次哨兵。
- smoke 用自有测试库/夹具、自有端口/进程，结束清理；不得终止用户其他进程，不访问生产环境。
- CI：frozen install、类型、lint、离线测试、构建、真实 Mongo 集成、核心浏览器 smoke；检查命令非零立即失败。
- 文档提供从干净 checkout 的启动顺序、示例配置、seed、验证及停止命令；此阶段不声称已建立线上环境。

## 5. 前端验收
