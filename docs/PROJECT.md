# 桂花图书馆：项目总览

更新日期：2026-11-15。定位依据：用户确认希望做一个自己感兴趣、对自己有用、能分享给他人使用的网站，并借此实践完整技术链路。

当前进度：M1（工程与公开书库）已交付，本地验证通过；M2–M5 未开始；尚无线上环境，交付分支为 `dev`。

## 为什么做

产品目标是一个多人分享阅读记录的小型社区：自己能持续记录和展示阅读，别人也能建立自己的内容并交流。

技术目标是亲手完成从后端编码、前端联调、本地测试到线上多环境发布和运维的全过程；遇到真实需求时，再探索中间件和架构演进。产品交付和技术学习都是本项目的成果。

## 用户与核心流程

| 用户 | 核心能力 |
|---|---|
| 访客 | 浏览公开书籍、按正在读/已读完筛选、查看介绍、书评和公开评论 |
| 登录用户 | 邮箱或 GitHub 登录、维护资料、发布和维护自己的书籍记录及评论 |
| 管理员 | 管理书籍、用户和角色，按发布用户及阅读状态筛选，处理违规内容 |

核心闭环：浏览 → 注册/登录 → 发布阅读记录 → 他人浏览并评论 → 作者继续维护 → 管理员保障秩序。

现有 books 模型绑定 ownerId、阅读状态和书评，代表发布者的一条独立阅读记录。M1 已确认：同一书名允许多条记录，评论归属具体记录，不建立全局公共书目或去重服务；后续若拆分公共书目需先记录迁移方案。见 [待决事项](DECISIONS.md)。

## 首版范围

- 公开书库、分页、状态筛选、详情和原生纯文本评论读取。
- 邮箱注册/登录、GitHub OAuth、退出和会话撤销；用户名 ASCII 且唯一。
- 用户名、性别、头像和个性签名的资料维护。
- 登录用户发布、维护自己的书籍和评论；归属由服务端确定。
- 管理员书籍、用户及角色管理，服务端权限检查、组合筛选和必要审计。
- 可运行的本地环境、隔离的自动化测试、CI，以及逐步建立的线上验证环境与生产环境。

不纳入首版：推荐算法、关注私信、支付、复杂搜索、多租户、嵌套评论和点赞。GitHub 外部评论是可选扩展，与 GitHub 登录分开；已有原生评论不依赖第三方评论产品。

按已有范围，不做验证码、强制邮箱验证、密码找回；仍保留密码哈希、限流、统一凭据错误与账号禁用能力。删除、发布生命周期等未决规则不因整理自动确定。

## 如何实现

```text
Vue 3 / Vite 浏览器页面
        ↓ HTTP / RESTful
NestJS API：输入校验、会话、权限、业务服务
        ↓ Mongoose
MongoDB：用户、身份、书籍、评论、会话、角色

pnpm workspace：apps/web + apps/api + packages/contracts
```

前后端共享 DTO/schema、状态枚举和错误约定，浏览器不依赖数据库模型。公开响应剔除敏感字段；后端检查身份、资源所有权和管理员权限。具体接口以 [API 契约](contracts/restful-api.md) 为准。

先形成一个可运行的模块化应用；只有出现明确用途才拆服务或引入新基础设施。已有技术栈保留，不因重新整理文档换栈。

## 技术实践怎么推进

| 实践方向 | 落地方式 |
|---|---|
| 后端工程 | 模块组织、校验、错误映射、索引、分页、认证授权、并发唯一性 |
| 测试 | 行为测试、真实测试数据库集成、浏览器核心流程、CI |
| 部署与运维 | 环境配置、构建产物、反向代理/TLS、日志、健康检查、备份恢复与回滚 |
| 多环境 | 本地开发与测试先隔离，再建立线上 staging 与 production，明确数据库、凭据及 OAuth 回调边界 |
| 中间件探索 | 按具体问题实验，例如缓存热点查询、队列处理后台任务；记录引入前后的效果和运维代价 |

中间件不是首版必选清单。学习实验可以独立分支或独立配置进行，不能让正式核心流程依赖尚未验证的实验结果。即使没有规模压力，也可以为学习做受控实验，但应说明实验目的，不把它描述成已证实的性能需求。

## 数据与安全边界

- 阅读状态仅 reading / finished；公开 API 仅返回 published 书籍及其公开评论，隐藏与不存在统一 404。
- ownerId、authorId、角色和审计字段由服务端确定；修改用户名不改变历史资源归属。
- 用户名、归一化邮箱和 OAuth provider subject 用数据库唯一索引保证唯一，不能仅靠先查后写。
- 密码只存安全哈希，会话密钥不明文落日志；会话支持过期、撤销和禁用用户失效。
- 所有写入做输入白名单及长度校验；所有列表分页有上限、排序白名单及匹配查询的索引。
- 公开 DTO 不返回邮箱、密码哈希、OAuth 凭据、会话秘密或角色内部字段；错误不泄露数据库和堆栈。
- 公开内容兼顾键盘、移动端、封面失败与减少动画设置。评论使用纯文本并安全渲染。
- 数据库变更记录兼容性和恢复方式；不通过删除生产数据实现回滚。
